# Lucia Raccoon | Интегративный психолог

Персональный сайт-визитка для интегративного психолога и сексолога Полины Гараниной (Lucia Raccoon). Проект разработан с акцентом на премиальный, журнальный (editorial) дизайн, минимализм и удобство использования на мобильных устройствах.

## 🌟 Особенности проекта

*   **Премиальный дизайн:** Использование элегантной типографики (Cormorant Garamond + Montserrat), спокойной и эстетичной цветовой палитры.
*   **Адаптивность:** Полностью отзывчивая верстка, оптимизированная под экраны любого размера (десктоп, планшет, мобильный).
*   **Интерактивность:** Использование библиотеки Lenis для плавного скроллинга (smooth scroll), интерактивный горизонтальный таймлайн на чистом CSS, элегантные анимации появления (fade-in) при прокрутке.
*   **PWA (Progressive Web App):** Поддержка Service Worker'а и манифеста, что позволяет установить сайт на главный экран смартфона и ускоряет загрузку благодаря кэшированию.
*   **Vanilla Stack:** Проект написан на чистом HTML, CSS и JavaScript без использования тяжелых фреймворков, что гарантирует максимальную скорость работы.

## 📂 Структура проекта

Проект организован по классической и интуитивно понятной структуре:

```text
psyweb/
├── index.html        # Главная страница (HTML5)
├── manifest.json     # PWA манифест для установки приложения
├── sw.js             # Service Worker для кэширования и офлайн-доступа
├── README.md         # Описание проекта
├── css/
│   └── style.css     # Основные стили, анимации и медиа-запросы
├── js/
│   └── script.js     # Логика плавного скролла и Intersection Observer
└── assets/           # Медиа-файлы (изображения)
    ├── about_portrait.jpg
    ├── hero_portrait.jpg
    └── ...
```

## 🛠 Технологии

*   **HTML5 / CSS3:** Семантическая верстка, CSS Flexbox и Grid.
*   **JavaScript (ES6):** Нативный JS для интерактивных элементов.
*   **Lenis:** Легковесная библиотека для плавного скроллинга.
*   **FontAwesome:** Иконки социальных сетей.
*   **Google Fonts:** Шрифты Cormorant Garamond (заголовки) и Montserrat (основной текст).

## 🚀 Развертывание (Deployment)

Поскольку это статический сайт, его можно развернуть на любом бесплатном хостинге за пару минут:
1. Загрузите файлы в репозиторий GitHub.
2. Используйте **GitHub Pages**, **Vercel** или **Netlify** — просто подключите репозиторий, и сайт будет доступен онлайн. Никакой предварительной сборки (build) не требуется.

## ✏️ Как вносить изменения

*   **Текст и структура:** Редактируйте файл `index.html`. Все разделы имеют четкие комментарии (например, `<!-- About Section -->`).
*   **Стили и цвета:** Основные цвета и шрифты вынесены в переменные (`:root`) в самом начале файла `css/style.css`.
*   **Анимации:** Управляются через классы `fade-in-hidden` и `fade-in-visible` в связке с Intersection Observer в файле `js/script.js`.
